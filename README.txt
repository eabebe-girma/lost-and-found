CAMPUS LOST & FOUND

A mobile lost-and-found platform designed to make it easier for students to report, search for, and recover lost belongings on campus.
Instead of relying on scattered group chats or social media posts, the platform uses AI-powered image-text similarity to help connect 
lost-item descriptions with reported found items.

Status: In active development — backend functionality is implemented and the frontend is being refined.

FEATURES:

📸 Report Found Items — Upload a photo of a found item and provide its location.

🔎 Report Lost Items — Describe a lost item using natural language.

🤖 AI-Powered Matching — Uses OpenAI's CLIP model to compare text descriptions with images of found items.

📊 Similarity Ranking — Potential matches are ranked based on semantic similarity.


The app uses CLIP to generate embeddings for found-item images and lost-item descriptions. When a user reports a lost item, its text
embedding is compared against stored image embeddings, and the most similar found items are returned as potential matches.
